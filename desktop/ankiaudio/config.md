**Read Aloud settings.** Voice, speed and on/off are also in **Tools → Read Aloud**.

- `enabled`: read each card side automatically. When off, **P** still reads on demand.
- `voice`: an Edge neural voice name, e.g. `en-US-AndrewMultilingualNeural`, `en-GB-SoniaNeural`.
- `speed`: `"+0%"` is normal; `"-20%"` slower, `"+20%"` faster.
- `line_pause_ms`: silence between lines (word, definition, example…).
- `lead_in_ms`: silence before each reading, so Bluetooth headphones don't clip the first syllable.
- `volume`: 0.0 to 1.0.
- `silence_card_audio`: don't autoplay the card's own `[sound:…]` files while reading aloud (**R** still replays them).
- `prefetch_next_cards`: how many upcoming cards to download audio for in advance.
